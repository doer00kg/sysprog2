## Регістри MPU-6050, які використовує драйвер

| Регістр | Адреса | Значення | Призначення |
|---|---|---|---|
| WHO_AM_I | 0x75 | читання, очікується 0x68 | ідентифікація чипа |
| PWR_MGMT_1 | 0x6B | 0x01 | вийти зі сну, тактування від PLL гіроскопа X |
| SMPLRT_DIV | 0x19 | 0x04 | частота вибірки 1 кГц / (1 + 4) = 200 Гц |
| CONFIG | 0x1A | 0x03 | цифровий фільтр DLPF 44 Гц |
| GYRO_CONFIG | 0x1B | 0x00 | ±250 dps |
| ACCEL_CONFIG | 0x1C | 0x00 | ±2 g |
| ACCEL_XOUT_H... | 0x3B | 14 байтів | дані одним читанням |
